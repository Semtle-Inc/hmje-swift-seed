HMJE `1.0.0-beta.1` 빌드 `2026100804`의 macOS ARM64 컴파일러 도구 네 개를 검증했습니다. 2026-10-09 03:44:39 KST에 전체 자동 절차가 종료 코드 0, 상태 `verified`로 완료되었습니다. 49개 단계가 모두 통과했으며 단계 실행 시간의 합은 약 43분입니다.

원본 결과는 [실행 보고서](../evidence/macos-arm64.json), 입력 식별값과 잘못된 입력의 거절 결과는 [검증 기록](../evidence/README.md)에 제공합니다.

## 적용 범위

최종 빌드는 배포본과 같은 분할 컴파일·ThinLTO 조건을 사용합니다. 소스 위치와 선택값 강제 추출 진단의 파일 경로에 적용하는 변환은 [부트스트랩 절차](bootstrap.md#소스-위치-경로)에 설명되어 있습니다.

이 결과는 위 환경과 고정된 입력을 기준으로 합니다. IDE, 플랫폼 라이브러리, 다른 CPU·운영체제 및 언어 전체의 정확성은 검증 대상이 아닙니다. Developer ID 인증서와 배포 타임스탬프는 재현하지 않았으며, 실제 서명된 배포 원본의 전체 바이트 재현을 주장하지 않습니다.

## 소스 경로 자동 감지

개인 경로 상수를 제거한 현재 검증 코드와 기존 49단계 전체 실행의 입력은 구분합니다. 기존 전체 실행 보고서는 변경하지 않으며 당시 입력 식별값을 `evidence/original-inputs.sha256`과 `evidence/original-seed-beta1.sha256`에 보존합니다. 경로 자동 감지 변경은 [별도 검사 기록](../evidence/source-prefix-portability.json)의 13개 검사를 통과했으며, 전체 부트스트랩을 다시 실행한 결과와는 구분합니다.
