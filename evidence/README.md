# 검증 기록

대상은 HMJE `1.0.0-beta.1` 빌드 `2026100804`의 macOS ARM64 컴파일러 네 도구입니다.

## 전체 실행 결과

[`macos-arm64.json`](macos-arm64.json)은 처음부터 실행한 자동 절차의 결과입니다. 종료 코드 0, 상태 `verified`이며 49개 단계가 모두 통과했습니다. Beta 1 2·3세대의 네 파일, 서명 전 배포 빌드 및 서명을 정규화한 실제 배포 사본이 각각 바이트 단위로 일치했습니다. 최종 소스·검증 코드 무결성 재검사도 통과했습니다.

## 입력 무결성

`inputs.sha256`은 현재 검증 코드·설정의 해시 목록, 소스 아카이브의 해시 목록 및 고정 버전 설정을 식별합니다. 저장소 루트에서 확인합니다.

49단계 전체 실행은 경로 자동 감지 도입 전의 검증 코드로 수행했습니다. 당시의 입력 식별값은 `original-inputs.sha256`과 `original-seed-beta1.sha256`에 보존합니다. 이 두 목록은 과거 실행의 식별 기록이며 현재 파일의 무결성 검사에는 아래 목록을 사용합니다.

```sh
shasum -a 256 -c evidence/inputs.sha256
shasum -a 256 -c reference/seed-beta1.sha256
```

실제 비교 파일은 Beta 1 macOS ARM64 DMG에서 가져왔습니다. 해당 DMG의 SHA-256은 `ec507bbbb79d14146a998d6cab03f875320da3c1d5e017371e8cfa94bcecd357`입니다. 검증 명령의 입력 무결성 검사 대상은 DMG에서 추출한 네 실행 파일입니다.

## 실패 판정 확인

`negative` 폴더의 보고서는 의도적으로 잘못된 입력을 사용하여 실행한 결과입니다. 모두 종료 코드 1로 중단됐으며 HMJE 컴파일 단계에 진입하지 않았습니다.

| 보고서 | 변경한 입력 | 중단 단계 |
| --- | --- | --- |
| `source-integrity.json` | 초기 소스 아카이브에 한 바이트 추가 | `source-integrity` |
| `seed-integrity.json` | 부트스트랩 패치 코드에 줄바꿈 추가 | `seed-integrity` |
| `missing-release.json` | 존재하지 않는 비교 파일 폴더 지정 | 비교 파일 폴더 검사 |
| `release-integrity.json` | 배포 컴파일러 파일에 한 바이트 추가 | `release-integrity` |

경로 변환은 소스 위치 기록과 선택값 검사 오류 메시지의 경로만 변경하는지 별도로 확인했습니다. 허용한 두 기록과 일반 반환 명령을 함께 입력하면 경로 두 곳만 변환됐고, 일반 호출 명령에 나타난 경로 문자열은 거절됐습니다.

## 경로 설정 변경 검증

[소스 경로 이식성 검사](source-prefix-portability.json)는 배포 파일의 소스 경로를 자동으로 읽고 빌드에 전달하는 기능의 검사 결과입니다. 실제 Beta 1 비교 파일의 경로가 기존 재현 기준과 같은지 확인했으며, 다른 접두 경로·공백·기록이 없는 최적화된 도구·모호한 입력·환경 변수 전달·HMIR 변환 및 거부 계약 등 13개 검사가 통과했습니다. 빌드 환경 전달은 시험용 도구로 검사했습니다. 변경 후 Swift 검증 드라이버의 타입 검사와 셸 문법 검사도 통과했습니다. 전체 Swift 부트스트랩을 다시 실행한 결과와는 구분합니다.
